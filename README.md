# Echoes of Room 104 — Unity Project

Welcome to the repository of **Echoes of Room 104**, a 2D Point-and-Click psychological mystery game built with Unity. 

---

### 1. Introduction & Team
*   **Game Title:** Echoes of Room 104
*   **Genre:** 2D Point-and-Click Adventure / Psychological Mystery
*   **Art Style:** Stylized, atmospheric 2D hand-drawn aesthetic (inspired by *Sally Face* and *Fran Bow*).

### 2. Core Idea & Lore
The player wakes up as a teenager trapped inside a surreal, shifting motel room. To escape, they must interact with the environment, unlock memories, and solve the dark secrets hidden within the room's walls. The atmosphere is eerie and mysterious but focuses on narrative and clever puzzles rather than cheap jump-scares.

### 3. Gameplay Mechanics (Responsive Inputs)
*   **Point-and-Click Exploration:** Simple, reliable mouse/touch controls to inspect objects and move around.
*   **Inventory System:** Collect items, inspect them closely, and drag-and-drop them onto environmental puzzles to trigger events.
*   **Interactions:** Fully script-driven clickable objects ensuring robust, exploit-free gameplay.

### 4. Progression & Content
*   **Progression Loop:** The game features **3 Chapters (Levels)**. As the player unravels the story, the room changes its visual state (getting darker and more surreal), and the puzzles become progressively harder.
*   **Content Variety:** Includes item-combination puzzles, environmental riddles (finding codes hidden in background layers), and unique story dialogues.

### 5. Tech Stack & Features
*   **Adaptive UI:** The main menu and inventory bar dynamically adjust to different screen resolutions (PC/Mobile support).
*   **Persistent Saves:** Game progress (Current Chapter and Inventory state) and User Settings (Audio Volume) are automatically saved between gaming sessions via `PlayerPrefs`.
